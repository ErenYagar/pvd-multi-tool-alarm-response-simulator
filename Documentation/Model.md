# 模型、單位與教學假設

SIMULATED：通用設備概念與應變練習。非台積電或設備商正式系統、內部 SOP、真機配方或安全控制器。

所有數值、門檻、支援時間均為教學設定。並非經驗證的數位分身，不可套用到真機。

## 唯一狀態來源

純 C# `Simulation` 擁有四個獨立 Tool、兩個 Branch、警報、任務及事件。每 0.1 模擬秒固定步進，整數 tick 推導共同時鐘。沒有亂數。歷史每 0.5 秒採樣；警報則在觸發的精確步進保存 First-Fail。Unity 3D、GUI、趨勢及報告都讀同一狀態。鏡頭、頁籤及選取不參與模型步進。

渲染迴圈累積時間，以固定步進追趕，不丟棄欠下的模擬時間；低幀率時可能比設定速度慢。訓練暫停凍結全部設備、支援、情境注入與驗證。首頁沒有運行；明確開始後才步進。

`Assets/PvdSimulator/Resources/scenario-config.json` 集中全部主要模型參數、門檻、時間。Config.Validate 檢查有限正值與門檻順序。相同設定與相同 tick 操作序列會產生相同模型資料與事件（匯出資料夾的 UTC／識別碼例外）。

## 動態方程

所有一階通道採解析更新：`next = target + (previous - target) exp(-dt/tau)`。

| 量 | 單位 | 方向／模型 |
|---|---|---|
| 濺鍍功率命令／回授 | kW | 回授以 0.6 秒時間常數追蹤命令；命令歸零不代表回授立即歸零 |
| 各台冷卻流量 | L/min | 6 × 共用供應係數 × 局部導通係數，以 2 秒時間常數響應 |
| 支路上游流量 | L/min | 兩台正常流量總和 × 共用供應係數，以 1.5 秒時間常數響應 |
| 冷卻入口溫度 | °C | 供應降低時入口溫度上升，支路及設備感測有不同延遲 |
| 設備溫度 | °C | `dT/dt = (1.7 × feedback_kW + residualHeat - 0.05 × flow × (T - coolant)) / thermalCapacity` |
| 殘熱 | 等效 °C/s 項 | 停機時取功率回授 × 0.8，7 秒時間常數消退；模擬保護後仍可能升溫 |
| 腔體壓力 | Torr | 泵運轉時追蹤加工 0.004／停機 0.0004；1.5 秒時間常數 |
| Load Lock 壓力 | Torr | `Pnext = Pbase + (P-Pbase) exp(-pumpRate × dt)`；正常 0.9 s⁻¹，異常 0.015 s⁻¹ 並提高背景負載等效平衡壓力 |
| 搬片 | 無因次 0–1 | 確定性循環。卡住時停止步驟，原點與終點確認通道矛盾，位置顯示未確認 |

這是重新設計的熱、冷卻、功率、真空與位置確認模型，沒有沿用蝕刻壓力／MFC/APC 模型。腔體／真空是教學上的有效一階容積；未建模真實氣體、泵曲線、電漿、靶材侵蝕、薄膜厚度與品質。3D 電源、管路與靶材部件是概念示意。

## 警報與事件順序

故障注入 → 模型／感測更新 → 依量測判定 → 保存 First-Fail 與原始警報事件 → 自動停功率／批次保留 → 保存自動保護事件。ACK、查看、解除均不覆寫快照。所有事件有單調遞增 sequence。

冷卻低於 3 L/min、溫度高於 60 °C、搬片矛盾逾 4 秒、Load Lock 抽氣 10 秒後仍高於 0.5 Torr 會觸發教學警報。現行情境無感測雜訊，因此不再加複雜 debounce。啟動於 18／20／22 秒，均可在設定修改。

優先度僅使用觀測值、新鮮度、晶圓確認狀態與已確認的保護狀態。溫度仍上升、晶圓未確認、保護未確認優先於已受控且空 Load Lock。歷史嚴重度另行保存，沒有以設備編號硬編碼排名。畫面與導覽不讀取 private 故障真值。

## 抽象處置與人力

主管核准需要零功率回授（<0.05 kW）、命令歸零、泵運轉、溫度低於 55 °C 且上升率 ≤0.08 °C/s、新鮮量測、批次保留及操作者已確認保護。模擬維修另需主管核准；位置未確認先由 EE 獨立確認，不能直接搬片修復。

有限現場 EE 一位、廠務一位；主管及 PE 是遠端通報角色，可並行。請求 → 接手（至少 2 秒）→ 處理 → 回報。位置確認 10 秒、局部處置 18 秒、廠務 22 秒、主管／PE 5 秒，均為可調教學參數。排隊和處理中每個 tick 都重新檢查條件，失效則中止且不修改故障。請求可查看回報事件；這些通報完全留在模擬器。

共同原因需跨台對照、管路連接、上游量測及歸組後向廠務提出；近期證據有效 45 秒。廠務確認／處置是唯一能恢復共用供應的操作；局部處置只改局部導通。歸組保留所有原始警報，並不證明原因。

## 驗證與產品分離

解除警報要求全部 ACK、實際量測回常及停機條件。處置完成後才可啟動模型驗證：命令 0.8 kW，冷卻 ≥5.5 L/min，設備溫度 ≤46 °C 且 |dT/dt|<0.15，功率回授誤差 <0.03 kW，位置通道一致且位置已確認，Load Lock ≤0.5 Torr。搬片異常會重新走 5 秒轉移模型；真空異常會由 760 Torr 重新抽氣。

所有項目必須同時連續滿足 15 秒；任何中斷重設穩定計時；75 秒逾時則保持停止。通過後停功率，顯示「驗證完成、待模擬授權」，須主管另行核准新批次。受影響晶圓沒有品質量測，即使 PE 已接手仍保持「待 PE 評估」，不提供虛構產品放行。

## 已知範圍限制

- 兩個固定教學情境，沒有 MES、配方編輯、多人、真實控制器或遠端連線。
- 正常機台使用循環搬片示意，沒有整批 lot 庫存或全套製程步序。
- 歷史保存整個回合，適合數分鐘教學；未設計數天資料留存。
- 文字理由只驗證選項能否由當時資料支持；自由文字不做語意評分。
- 原始場景為具自動接線的 SimulatorApp 入口；完整設備在 Play 時程序化建立。多台共用同一幾何生成器，但不共用 Tool 狀態。
